# If I Can Shoot Rabbits

Choose your device. Download the game, open the installer, then play.
**No GitHub account or programming tools needed.**

| Your device | Download | Install |
| --- | --- | --- |
| Windows | **[DOWNLOAD FOR WINDOWS](https://github.com/Mikieb1982/badfodder/releases/latest/download/Shoot-Rabbits-Windows.exe)** | Open the downloaded installer and follow the steps. Start the game from its desktop shortcut. |
| Mac | **[DOWNLOAD FOR MAC](https://github.com/Mikieb1982/badfodder/releases/latest/download/Shoot-Rabbits-Mac.dmg)** | Open the download and drag the game into Applications. Supports Intel and Apple Silicon. |
| Android | **[DOWNLOAD FOR ANDROID](https://github.com/Mikieb1982/badfodder/releases/latest/download/Shoot-Rabbits-Android.apk)** | Open the download, allow installation from that source when asked, and install. |
| Chromebook | **[DOWNLOAD FOR CHROMEBOOK](https://github.com/Mikieb1982/badfodder/releases/latest/download/Shoot-Rabbits-Chromebook.zip)** | Linux must be enabled. Extract the ZIP and follow READ-ME-FIRST.txt. Both processor versions are included. |

Campaign, mission select and Resistance work offline from the first launch.
Your progress saves on your device. Multiplayer is available when connected.

Send friends this download page: **https://github.com/Mikieb1982/badfodder/releases/latest**

These are early distribution builds. Windows and Mac installers are unsigned,
so your device may show a security prompt. On Mac, use System Settings → Privacy
& Security → Open Anyway if offered for this app. Android is test-signed; export
your campaign save before replacing an installation if a future update requires
uninstalling. Chromebook Linux setup or missing system libraries may need internet
once; school/work devices may block Linux. This download does not include iPhone
or iPad support.
