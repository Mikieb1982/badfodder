# Painted arcade art direction

Built-in image generation created the four source atlases. Runtime WebP assets preserve their painted detail and genuine alpha. Technical packing cropped transparent cell bounds, normalised padding and baselines, and encoded the atlases. No generated background is used as a replacement for the map.

Runtime assets: `assets/painted/materials.webp`, `assets/painted/troops.webp`, `assets/painted/trees.webp`, `assets/painted/landmarks.webp`. Layout metadata is in `assets/painted/manifest.json`.

The troop atlas has eight facings for squad, enemy and civilian characters. Independent leg crops and torso sway use the existing distance-driven gait. Landmarks use the established seven silhouettes as a layout reference, then fit back into their original sprite bounds. Roads, map footprints, vegetation anchors and POI coordinates are unchanged.
